# Baybisoap

First botanical catalogue draft for GitHub Pages. All 21 items are proposed concepts, not verified formulations or an enabled shop.

Publish from **main / root** in Settings → Pages. Set custom domain to **baybisoap.cuantor.com**, then enable HTTPS when available. GoDaddy CNAME: host `baybisoap`, target `nactuarial.github.io`.

## Pricing

USD references checked October 10, 2026. Bar soap $8; massage oils $15; lip balm $8; solid shampoo $12; 6 oz whipped shea body butter $24. Sources are recorded per product in `products.json` and on the page. The three massage concepts use the same category benchmark although only two reference oil blends were found. Liquid soap and sunscreen remain unpriced because no direct Unearth Malee match was found. These are category benchmarks, not equivalent sizes or formulas.

## Before launch

Confirm all product concepts, actual ingredients, pack sizes and prices; supply real product photographs and order/contact details. Confirm sunscreen specifications before making SPF or protection claims. No checkout, payment, or customer data collection is implemented.

## Editing

`index.html` is self-contained and needs no build or dependencies. `products.json` is the catalogue source snapshot; when editing manually, keep the embedded product data in `index.html` synchronized.
